# Nano Banana: step by step

All files are in this folder: **C:\Users\Crack\Desktop\projects\bite_size\screenshots**

## What you're doing

Each numbered folder (01 to 07) holds a rough draft called **scaffold.png**: green background, headline, phone. You give that draft to Nano Banana with a prompt, and it hands back a polished version. You save that next to the draft as **v1.png**. Do it 7 times.

## Shot 1 (do this first)

1. Open **gemini.google.com** and choose **Nano Banana Pro** (create image).
2. Click **+** and upload `01-know-what-you-owe\scaffold.png`.
3. Copy the **Shot 1 prompt** below, paste it in, and send.
4. Download the image and save it as `01-know-what-you-owe\v1.png`.
5. If you like it, also save a copy as `final\01-know-what-you-owe.png`. Make the `final` folder if it doesn't exist. If you don't like it, regenerate first.

## Shots 2 to 7 (same steps every time)

1. Start a **new chat** in Gemini.
2. Upload **two images, in this order**:
   1. that shot's `scaffold.png`
   2. `final\01-know-what-you-owe.png`. This is your approved shot 1, so all 7 come out matching.
3. Copy **that shot's prompt** below, paste it in, and send.
4. Save the result as `v1.png` in that shot's folder.

When all 7 `v1.png` files are saved, tell Claude **"done"**. Claude resizes, checks and finishes the set.
